# Play Hub

Play Hub is a browser-based multiplayer game platform built with React, TanStack Start, TypeScript, and Supabase.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Configure the Supabase URL and publishable key for the client, plus the server-side Supabase variables required by the application. Google OAuth is configured through Supabase Auth.

## Project goals

The V2 work will preserve the existing game rules while moving toward a modular, server-authoritative game architecture.
